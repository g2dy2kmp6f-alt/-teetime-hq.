# TeeTime HQ

Free, mobile-first golf tee-time organizer PWA.

## GitHub Pages
Upload all files to a repository, then go to Settings → Pages → Deploy from branch → `main` / root.

## MVP features
- Save tee times locally
- Friends list and invitations via native share
- Open spots
- Calendar `.ics` export
- Course directions
- Installable PWA/offline shell
- Live hourly weather forecasts from Open-Meteo (up to 16 days), based on entered course city/state. Shows temperature, rain chance, wind speed/direction. Free non-commercial API, no key. Location is city-level approximation, not exact course coordinates.

No build step or paid backend is required for this prototype.
